# Machine Learning – Assignment 3

## Fashion-MNIST Classification

This repository contains the complete solution to **Assignment 3 – Fashion-MNIST Classification**.

The assignment focuses on building, training, and comparing neural networks using TensorFlow and Keras.

## Project Files

- **`Assignment_3.ipynb`** – Contains all Python code, experiments, results, visualizations, and answers to Q1–Q4.
- **`pyproject.toml`** – Project dependencies.
- **`uv.lock`** – Locked dependency versions.

## Assignment Overview

- **Part A:** Build and compare four neural networks with different configurations.
- **Part B:** Answer theoretical questions Q1–Q4 about neural networks.
- **Part C:** Generate and analyze a confusion matrix to identify classification errors.

## Results

Experiment 1 (64 neurons, ReLU, Adam) achieved the highest validation accuracy of **88.88%** and a test accuracy of **87.29%**.

## Technologies

Python, Jupyter Notebook, TensorFlow/Keras, NumPy, Pandas, Matplotlib, and Scikit-learn.

All code, results, and written answers are included in `Assignment_3.ipynb`.
